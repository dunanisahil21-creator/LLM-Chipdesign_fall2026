# HW_ChipChat — ChipChat Assignment (LLM4ChipDesign)

Conversational hardware design with ChipChat: 8 notebook examples + an 8-bit
accumulator-based CPU example, generated via LLM (GPT-4o-mini through
OpenAI/Portkey) and verified with Icarus Verilog (iverilog).

## Contents
- `ChipChat_hw.ipynb` — executed notebook, all 8 examples + CPU example, outputs visible
- `ChipChat_Report.pdf` — summary report and reflections
- `binary_to_bcd/`, `sequence_detector/`, `shift_register/`, `abro_state_machine/`,
  `dice_roller/`, `lfsr/`, `sequence_generator/`, `traffic_light/` — generated Verilog,
  testbenches, and simulation logs per example
- `cpu_processor/` — 8-bit accumulator-based CPU design: prompts, generated Verilog, notes
